# Contributing

**This project is not accepting contributions.**

The source is published for inspection and private evaluation only, under
the terms in [LICENSE](LICENSE). It is not an open-source project and is
not run as one.

Please do not open pull requests. Any that arrive will be closed unread,
which is no reflection on the work — accepting a patch would create
licensing and provenance questions this project is not set up to answer.

## What is welcome

**Security reports.** If you find a vulnerability, please open an issue
describing the impact without a working exploit, and say that you would
prefer to share details privately. This controls mains electricity in
people's homes, so these are taken seriously and will get a reply.

**Safety concerns.** If you spot something in the control logic,
interlocks or failure handling that could put someone at risk, say so.
That is the most valuable thing anyone reading this code can do.

**Questions and corrections.** Issues pointing out a documentation error,
a mistaken claim, or behaviour that does not match what the docs describe
are genuinely useful.

## Permission requests

Any use beyond the evaluation permitted by Section 2 of the licence —
commercial use, redistribution, manufacture, or deployment — needs a
separate written agreement. Open an issue to start that conversation.
